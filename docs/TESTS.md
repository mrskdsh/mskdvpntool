## Что тесты **не** покрывают (см. `HARDWARE-CHECKLIST.md`)

- Настоящие образы Docker и реальные AmneziaWG-контейнеры.
- Доступность портов у реальных хостеров, работа UDP в мобильных сетях.
- Импорт ссылок `vless://`, `hysteria2://`, `ss://` в настоящих приложениях (Happ, v2rayNG, AmneziaVPN и др.).
- Версия протокола `3` в `vpn://` для AmneziaWG 3.1 (формат выбран по аналогии, нужна проверка в приложении).
- Отображение интерфейса на реальных телефонах (проверялось в эмуляции 390 px и 1280 px).
- Установка на удалённые серверы с обычным (не root) SSH-пользователем.
