# Mr. Skdsh VPN — панель управления AmneziaWG

Небольшая self-hosted VPN-панель для личного/семейного сервера: админ видит всех
подключённых, задаёт лимиты трафика, генерирует доступы одной кнопкой; каждый
пользователь видит только свой остаток трафика и QR-код для подключения.

Написана как альтернатива тяжёлым панелям (типа X-UI/Marzban) под конкретный
кейс: сервер на AmneziaWG для 8-10 человек, лимит трафика на хостинге, и
никакого желания разбираться с Reality/Xray, когда обычный WireGuard-протокол
и так стабильно проходит DPI.

## Архитектура

```
Браузер → Vercel (React SPA)
             │
             ├─→ Supabase (Auth, роли, история заявок)
             │
             └─→ Vercel Serverless Functions (/api/*)
                     │  прокси с секретным ключом
                     ▼
                 Backend на VPS (Node.js/Express)
                     │  управляет живым интерфейсом
                     ▼
                 AmneziaWG (Docker-контейнер)
```

Backend на VPS — единственное место, которое реально трогает WireGuard:
генерирует ключи, дописывает пиров в конфиг, читает `wg show ... dump` для
статистики трафика, и по крону сам блокирует тех, кто исчерпал лимит.

## Стек

React 18 · Vite · Framer Motion · Supabase (Auth + Postgres + RLS) ·
Vercel Serverless Functions · Node.js/Express на стороне VPS

## Фичи

- Круговой индикатор расхода трафика в стиле топливного датчика — цвет меняется
  по мере приближения к лимиту
- Авто-блокировка пира при превышении лимита (cron на backend, раз в 10 минут)
- У одного человека может быть несколько устройств (ПК + телефон) под одним
  логином — переключаются вкладками в личном кабинете
- QR-код и текстовый конфиг генерируются на лету, приватный ключ никогда не
  покидает сервер до момента показа конкретному владельцу
- Row Level Security в Postgres — каждый видит только свои данные, роль
  проверяется на уровне базы, а не только в UI

## Что не реализовано (сознательно, для первой версии)

- Email-уведомление админу при заявке на подключение — заявка падает в таблицу,
  смотреть пока нужно руками через Supabase Table Editor
- Самостоятельная регистрация — логины заводит админ вручную/скриптом
